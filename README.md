# Leonardo Vitório Rezende

Estudante de Engenharia de Computação na Ufes. Mantenho os sistemas do PET Engenharia de Computação e do IntroComp e uso agentes de LLM para programar, revisar e automatizar a manutenção deles.

## No ar

- [Estatísticas das disciplinas](https://estatistica.pet.inf.ufes.br): aprovação, notas e dificuldade de cada disciplina de Engenharia de Computação nos currículos 2008 e 2022. Refiz a interface.
- [PET Game Jam](https://gamejam.pet.inf.ufes.br) ([código](https://github.com/pet-eng-comp-org/game-jam)): inscrição das equipes e vitrine dos jogos, em Next.js e Express com Prisma.
- [Site do PET](https://pet.inf.ufes.br) ([código](https://github.com/pet-eng-comp-org/site-pet)): fiz o menu, o painel administrativo e os formulários.
- [BOCA de treino do Topcom](https://boca.pet.inf.ufes.br/boca) ([código](https://github.com/pet-eng-comp-org/boca-treinamento)): juiz de programação competitiva para treinar fora da prova.

## Infraestrutura

- [moj-docker](https://github.com/pet-eng-comp-org/moj-docker): o MOJ, juiz da Maratona SBC, em Docker com o juiz incluído.
- [monitor](https://github.com/pet-eng-comp-org/monitor): avisa pelo ntfy quando um site da VM sai do ar.

TypeScript, Next.js, Express, PostgreSQL, MySQL, Docker, Traefik, GitHub Actions e Claude Code.
